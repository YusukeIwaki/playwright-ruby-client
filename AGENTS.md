# AGENTS.md

This file contains only the checks that must be verified first.  
For detailed rules, see `AGENTS/*.md`.

## Must Check First

1. Determine first whether the task is a Playwright version upgrade.
2. For Playwright version upgrades, perform the upstream PR review before porting.
- Review the upstream Playwright PRs for the target release in order.
- Summarize each PR's behavior, Ruby porting need, client-side changes, and tests.
- Follow `AGENTS/upstream_pr_review.md`.
3. Confirm generated-code handling.
- `lib/playwright_api/*.rb` is auto-generated by `development/generate_api.rb`.
- `lib/playwright_api/` is not tracked by Git. Do not edit generated files manually.
4. Confirm change order.
- For version upgrade work, update tests first, then implement `lib/playwright/**`.
5. Confirm generation and diff consistency.
- Update `development/api.json`, run generation, and verify generated diffs.
6. Confirm CI-required generated files.
- `development/api.json`
- `documentation/docs/**`
- `development/unimplemented_examples.md`
7. Confirm RSpec execution mode (critical).
- Run RSpec via `rbenv exec`.
- On failure, rerun with `DEBUG=1` and inspect protocol logs.
8. Confirm Ruby 2.4 compatibility for example specs.
- `spec/integration/example_spec.rb` runs in CI as `(chromium/Ruby2.4) example_spec`.
- Keep code used by `example_spec.rb`, including examples in `development/generate_api/example_codes.rb`, compatible with Ruby 2.4 syntax.
